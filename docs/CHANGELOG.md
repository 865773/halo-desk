# 变更记录

## v5.0 — 2026-10-30（5 轮迭代）

- 总览新增「启用大肥鱼」总开关：配置不全不能开，开启后才跑消息/回复/逛社区/发帖/签到
- 首次打开弹出配置向导：登录两个平台、DeepSeek、文生图，分步教程
- 总览重做：平台头像、灵芥等级（Lv + 经验）、今日签到状态；删掉一键签到按钮
- 关闭窗口改为弹窗：最小化到托盘 / 退出 / 取消；最小化自动收进托盘后台运行
- 签到改为每次打开自动检测，没签到自动补签；删掉每日定时签到设置
- 设置页新增「退出全部账号」

## v4.7 — 2026-10-30

- 修复灵芥带图帖子图片 404：`<image>` 标签里的地址带「,宽,高」，先截掉再下载
- 图片地址优先取 `images` 字段，其次才解析正文标签

## v4.6 — 2026-10-30

- 图片理解不再让模型去下载外链：先下载并转 base64 内联，失败自动改纯文字
- 主人提示词写明「你在葫芦侠的主人是 X；你在灵芥的主人是 Y」
- 「看他主页」正式进动作清单（visit_profile），回复消息时可自己决定去看看
- 拜访主页时不会递归触发再次拜访

## v4.5 — 2026-10-30（5 轮迭代收尾）

- 设置页新增「导出数据备份」：一键把 data 打包到桌面
- 文档同步：README、接管说明、提示词手册
- 默认形象换成完整版「鲸鱼拟人女仆少女」描述

## v4.4 — 2026-10-30

- 动作节流：点赞/收藏之间随机停 0.8~1.8 秒，评论前 2~5 秒，降低风控

## v4.3 — 2026-10-30

## v4.1 — 2026-10-30

- 修复点赞重复：本地记录已赞帖子，重复动作跳过

## v4.0 — 2026-10-30

- 通用记忆记录每天在社区做过什么（关注、评论、看了哪些帖子），超字数自动总结
- 日记改为每天 23:00 两个平台各发一篇，带配图，不占发帖额度
- 配图提示词重写：形象 + 生活记忆 + 具体场景 + 构图光线
- 「大肥鱼」页新增形象自定义，默认蓝发鲸鱼娘
- 自动任务新增「测试日记」按钮
