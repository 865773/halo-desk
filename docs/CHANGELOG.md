# 变更记录

> 只记录对使用者有影响的变更；版本号与界面左下角一致。

## v3.3 — 2026-10-29

- 用户记忆列表显示昵称（`names_*.json`，启动时后台补全）
- 只有别人主动互动（评论/回复/@）才写用户记忆；自己的操作不再写入
- 移除社区页的「记忆与亲密度」卡片（仅 UI）

## v3.2 — 2026-10-29

- 表情白名单过滤：自创 / 串台表情发送前自动剔除
- 灵芥表情表去重、过滤非法项（160 个）

## v3.1 — 2026-10-29

- 修复用户记忆列表白底白字，改为深色可读配色

## v3.0 — 2026-10-29

- 「记忆」页：通用 / 生活记忆可视化，字数与上限、手动压缩
- 用户记忆移入两个社区页，列表 + 点击查看
- 数据目录改为 exe 同级（便携），设置页可复制路径

## v2.9 — 2026-10-29

- 记忆超字数自动总结压缩（1500 / 800 / 1200 字）
- 文生图支持多模型轮换（余额/额度用完自动换下一个）
- 项目打包到桌面，新增接管文档

## v2.8 — 2026-10-29

- 灵芥上传使用接口返回的 `uploadHost`，失败回退七牛区域域名
- 两平台表情系统独立接入提示词

## v2.7 — 2026-10-29

- 修复灵芥图片上传（域名 + PNG/JPEG 后缀）
- 修复自由行动 `random` 未导入导致的报错

## v2.6 — 2026-10-29

- 两平台独立发帖：额度、间隔、24 小时均分分别计算
- 测试发帖按钮拆成「葫芦侠 / 灵芥」
- 发帖后判定「审核中」

## v2.5 — 2026-10-29

- 两平台主人 ID 分离
- 生活记忆更丰富（出门、地点、天气）
- 配图按生活记忆 + 随机场景生成，降低同质化
- 已评论帖子不再重复查看/评论

## v2.4 — 2026-10-29

- 支持灵芥 `at_comment`（@ 我）通知
- 新增收藏列表目标（my_favorite_first）
- 葫芦侠审核通知解析（type_id=1）
- 修正「我的主页」被解析成鱼自己主页的问题

## v2.3 — 2026-10-29

- 拆分「消息轮询 10 秒」与「逛社区间隔」
- 评论重复时给出真实原因，不再显示「动作没有生效」

## v2.2 — 2026-10-29

- 新增取消关注 / 取消点赞 / 取消收藏动作
- 发帖后评论可见性复查

## v2.1 — 2026-10-29

- 消息回复去重（本地 + 服务端）
- 唤醒间隔跨重启持久化

## v2.0 — 2026-10-29

- 固定动作清单（15 种组合 + 独立动作）取代关键词匹配
- 逛社区支持「换社区」「先看主人」

## v1.9 — 2026-10-29
