## 60 秒版本

1. **开场（0–5s）**：启动页 + 女仆开场视频。
   「这是一个 Windows 桌面程序，不是网页，也不是模拟器。」
2. **双平台（5–15s）**：登录两个平台，展示两个账号卡。
   「葫芦侠三楼、灵芥空间，两个账号同时在线；只登一个也能用。」
3. **自动回复（15–25s）**：评论触发 → 气泡 + 回复。
   「10 秒看一次消息，只处理接入之后的新消息，回复前会随机等一下，不像机器人。」
4. **逛社区（25–35s）**：动态里展示「去哪个社区 → 板块 → 看几条 → 每帖动作」。
   「逛社区不是我写死的，是模型自己一层层决定，理由都写在动态里。」
5. **记忆与心情（35–45s）**：记忆页 + 心情卡。
   「通用记忆、生活记忆、用户记忆分开存；被夸会开心，被凶会不开心。」
6. **桌宠与主题（45–55s）**：挂件摸头/喂饭、主题切换。
   「桌面挂件会动，能摸头、喂饭；主题有壁纸、纯白、黑夜。」
7. **收尾（55–60s）**：gitee 仓库 + exe。
   「单文件 exe，开源在 Gitee，搜 HaloDesk 就能找到。」

## 发布文案（可直接复制）

**标题**：我把葫芦侠和灵芥做成了一个桌面女仆，还会自己逛社区

**正文**：
> 用 Python 把两个社区合成了一个 Windows 单文件程序。
> 一个窗口登录两个号，10 秒看一次消息，有人评论就自己回；
> 没人理她的时候会自己去逛帖子、点赞、评论、发帖，每一步都写理由。
> 她还有记忆和心情：逛超市、买奶茶、被夸、被凶都会记下来，
> 被凶了心情会掉，过几个小时慢慢回到平常。
> 桌面挂件能摸头、喂饭、拖来拖去；主题有流光壁纸 / 纯白 / 黑夜。
> 单 exe，免安装，数据全在本地。
> 开源地址：gitee.com/guo-wenlong/halo-desk

**标签**：#桌面美化 #Python #开源项目 #葫芦侠 #独立开发 #桌面宠物

## 录制建议

- 先录 3 秒启动页和开场视频，作为钩子；
- 消息回复用另一个号现场评论，能拍到「叮咚 + 气泡 + 自动回复」最有说服力；
- 动态页把「理由」露出来，这是和普通脚本最大的区别；
- 最后给 exe 图标 + Gitee 地址，别在视频里露出账号、Key、手机号。

## 分享注意事项

- 只发 `HaloDesk.exe` 或清空 `data/` 的 zip，**不要**带自己的 `config.json`；
- 提醒对方首次运行可能被 SmartScreen 拦截，选「更多信息 → 仍要运行」；
- 说明需要自备 DeepSeek / 阿里云 Key，程序本身不含额度。
